# 디자인 규칙

## 1. 콘셉트: 하얀 바탕 위 줄무늬 프로젝트 폴더
레퍼런스: 분홍·올리브 세로 줄무늬 폴더 아이콘, 깅엄 바탕 위에 폴더가 놓인 파일 창.
프로젝트 하나 = 폴더 하나. 나머지 화면은 최대한 덜어내 깔끔하게.

- 배경은 흰색. 짙은 색 면적(어두운 배경, 진한 색 판)은 쓰지 않는다
- 포인트 색은 폴더에서 뽑은 **분홍 · 올리브 · 세이지** 세 가지만. 다른 색을 새로 만들지 않는다
- 글꼴은 두 가지만 (Pretendard + DM Mono)
- 기울이기·손글씨·장식 소품은 쓰지 않는다. 정렬과 여백으로 정돈
- 이미지는 크게, 글은 짧게

## 2. 색
```css
--bg:         #FFFFFF;  /* 페이지 배경 */
--paper:      #FAF9F6;  /* 카드·자리표시 바탕 */
--line:       #EBE9E3;  /* 테두리·구분선 */
--ink:        #26261F;  /* 본문 */
--muted:      #72726A;  /* 보조 글 */
--pink:       #F5C8D0;  /* 폴더 줄무늬 */
--pink-soft:  #FCEDF0;  /* 결과 카드, 연락처, '내 담당' 칩 바탕 */
--pink-ink:   #B8566D;  /* 분홍 위 글자 */
--olive:      #7C8A47;  /* 폴더 줄무늬, 주 버튼, 번호 */
--olive-soft: #EEF0E4;  /* 올리브 칩·체크 바탕 */
--olive-ink:  #556030;  /* 올리브 위 글자, 강조 숫자 */
--sage:       #A8AB84;  /* 폴더 뒷판·탭 */
```
- 그림자: `--shadow` 하나만, 마우스를 올렸을 때만
- 모서리: 카드 14px(`--radius`), 버튼·칩은 완전 둥글게

## 3. 글꼴
| 역할 | 글꼴 |
|---|---|
| 제목·본문·라벨 | Pretendard (굵기로 위계: 800 제목 / 700 소제목 / 400 본문) |

## 6. 공통 부품 (js/components.js + css/base.css)
- **줄무늬 폴더** `folder()`: 세이지 뒷판 + 왼쪽 탭, 분홍·올리브 물결 줄무늬 앞판, 사이에 cover 종이. 올리면 종이가 위로 빠져나옴
- **대표 이미지 톤** `tone(project)`: cover 사진을 사이트 색 두 가지로 변환(홀수 프로젝트 올리브, 짝수 분홍). 홈 썸네일·폴더 속 종이·상세 상단에 적용. 썸네일은 같은 톤의 깅엄 판 위에 흰 테두리 종이처럼 놓음
- **키워드 문장** `keyLine()`: "키워드 — 설명" → 키워드 굵게. 긴 문단 대신 이 형식으로 짧게
- **칩** `chip()`: 기본(회색 테두리) / `pink`(내 담당) / `olive`(프로젝트 구분)
- **버튼** `button()`: 높이 44px 이상, `primary`는 올리브 채움
- **섹션 머리** `sectionHead()`: 올리브 번호 + 굵은 제목 + 영문 보조
- **명세 목록** `specList()`: 항목(mono, 회색) – 값, 얇은 구분선

## 6-1. 프로젝트 테마 (`theme` 필드)
두 프로젝트는 **뼈대(글꼴·카드·간격·부품·섹션 순서)가 같고, 색과 포인트 장식만 다르다.** 테마를 더 만들 때도 이 원칙을 지킨다.
- 색: 홈 폴더 배색과 같게. `css/project.css` 테마 블록에서 `--olive`(포인트)·`--pink`(강조: 내 담당·결과)·`--tint`(연한 종이색) 변수만 바꾼다
  - `beauty`(COSMOA): 하늘 포인트 + 크림 노랑 강조
  - `heritage`(한정선): 갈색 포인트 + 분홍 강조
- 공통 장식: 커버 캡처의 마스킹테이프, 제목 옆 스티커(`sticker`), 위쪽 테마 띠가 있는 연한 종이색 카드
- 테마별 포인트 장식은 하나씩만
  - beauty: 문제에서 결과까지 = 링 노트 + 손글씨, 내가 맡은 부분 = 폴라로이드 메모(`mine.notes`)
  - heritage: 결과물 세로 영상·포스터 = 아치 틀(`shape: "arch"`)
- 글꼴은 테마와 상관없이 Pretendard + DM Mono (손글씨는 beauty 장식 안에서만)

홈 폴더·프로젝트 카드·대표 이미지 톤도 같은 배색: beauty = 연하늘·크림 노랑(`tone-sky`), heritage = 분홍·갈색(`tone-cocoa`)

## 6-2. 톤과 모션 (레퍼런스: 미니멀 가구 브랜드 페이지)
- 바탕은 밝은 그레이지(`--bg: #F3F2EF`), 큰 면은 흰 카드(모서리 32~44px). 버튼은 검정 알약 + 흰 동그라미 화살표, 태그는 검정 테두리 알약(하나만 검정 채움)
- 홈 첫 화면: 아주 큰 검정 글자 'AX Archive' 위에 프로젝트 폴더가 오브제처럼 놓임. 왼쪽 작은 메뉴, 가운데 이름, 오른쪽 링크, 아래 '01 / 02 →'와 태그
- 프로젝트는 둥근 큰 카드(`/01`, 탭 알약, 제목, 화면, 아래 동그란 화살표). 카드 색은 폴더 배색의 아주 연한 톤
- 모션은 느리고 부드럽게, 한 번씩만
  - 큰 글자·상세 제목이 아래에서 천천히 올라옴, 폴더는 천천히 떠오른 뒤 아주 느리게 둥실
  - 스크롤 등장은 살짝 아래에서 페이드 (형제끼리 차례로), 숫자는 0부터 셈(`countUp`)
  - 폴더에 마우스를 올리면 카드 3장이 천천히 펼쳐짐, 카드 이미지는 살짝 확대·화살표가 돌아감
  - 상세 페이지 맨 위 2px 읽기 진행 막대
- 쓰지 않는 것: 흩어진 소품, 흐르는 띠, 따라다니는 커서, 기울기, 튀는 애니메이션
- '동작 줄이기' 설정이면 모션 전부 끔

## 7. 품질 기준
- 390px에서 가로 스크롤 없음, 본문 16px 이상(보조 라벨 12~14px 허용)
- 키보드 포커스 표시, `prefers-reduced-motion` 존중
- 이미지에 alt 텍스트
- 첫 화면 이미지 합계 1MB 이하 (cover는 WebP 권장)
